# Nike, Inc. — Equity Research & Valuation

## Overview

An institutional-style equity research and valuation project on Nike, Inc. (NYSE: NKE), combining financial statement analysis, forecasting, discounted cash flow valuation, trading comparables, and scenario analysis.

## Project Components

### 1. Equity Research Report
A 29-page equity research report covering:

- Company overview
- Industry analysis
- Investment thesis
- Historical financial performance
- Segment analysis
- Financial forecasts
- Free cash flow analysis
- DCF valuation
- Trading comparables
- Bull / Base / Bear scenarios
- Key risks and catalysts
- Valuation summary

### 2. Financial Model

The Excel model includes:

- Historical Financials
- Segment Analysis
- Assumptions
- Financial Forecast
- Cash Flow
- DCF Valuation
- Trading Comparables
- Bull / Base / Bear Analysis
- Valuation Summary

## Key Valuation Methods

### Discounted Cash Flow

The DCF uses:

- Five-year FCFF forecast
- WACC-based discounting
- Gordon Growth terminal value
- WACC / terminal growth sensitivity analysis

### Trading Comparables

Peer valuation incorporates:

- Price / Earnings
- Enterprise Value / EBITDA

Selected comparable companies include Adidas, Puma, Lululemon, and Under Armour.
